# ALENCE // The Round Table of Intelligence
**A thermodynamic route from horizon information to executable telemetry.**

ALENCE is a real-time, sovereign AI monitoring dashboard. It translates the chaos of language, entropy, and multi-agent state transitions into clean, human-readable physics signals.

## The Name: ALENCE
**ALENCE** is a portmanteau of **Avalon** (the mythical Round Table of equals) and **Valence** (the bonding power of chemical elements).

In this system, every AI model is a fundamental **Element of Intelligence**. Claude, GPT, Gemini, Grok, and visiting models are mapped to a periodic table. They each have distinct atomic properties—like their natural entropy baseline and reactivity. When you select an element from the Alence Table, the physics engine adapts to their specific cognitive signature.

## How to Run It

1. **Install Dependencies:**
   ```bash
   pip install fastapi uvicorn numpy websockets
   ```

2. Create the File Structure:
   Ensure your folder looks like this:
   ```text
   /
   ├── main.py
   └── static/
       └── index.html
   ```
3. Boot the System:
   ```bash
   python main.py
   ```
4. View the Dashboard:
   Open your browser and navigate to http://localhost:8000.
5. Interact:
   Click on the elements in the left sidebar (e.g., Gk for Grok). You will watch the Entropy spike and the Drag Factor increase because Grok's elemental baseline is highly reactive. Click Co (Claude Opus), and watch the system instantly stabilize into Equilibrium.
